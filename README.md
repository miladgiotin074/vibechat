# Vibe Chat 💜

مینی‌اپ تلگرام برای آشنایی و گفتگو: کشف با سوایپ، مچ، چت لحظه‌ای، لایک‌ها، عضویت ویژه با درگاه **تتراپی**، دعوت دوستان با هدیه، و اعلان‌ها از طریق ربات.
UI و امکانات از پروژه‌ی `rubikaDostyabi` (اپ اندروید) آمده و برای تلگرام بازنویسی شده است.

| مسیر | چیست |
|---|---|
| `apps/miniapp` | مینی‌اپ (React 19 + Vite + Tailwind 4 + `@tma.js/sdk-react` + Motion)، فارسی و راست‌چین، تم تیره |
| `apps/server` | API + WebSocket + ربات تلگرام (grammY) + worker (BullMQ) — Node.js 22 / TypeScript / Fastify / PostgreSQL / Redis |
| `apps/admin` | پنل مدیریت (Next.js) |
| `deploy` | Docker Compose با پروفایل‌های `data` و `app`، nginx با IP واقعی کلادفلر، اسکریپت آماده‌سازی Ubuntu 24 |
| `docs` | [معماری و مقیاس‌پذیری](docs/ARCHITECTURE.md) · [راه‌اندازی روی سرور](docs/DEPLOYMENT.md) |

## نصب روی سرور (Ubuntu 24.04)

روی یک سرور تازه، با کاربر root:

```bash
curl -fsSL https://raw.githubusercontent.com/miladgiotin074/vibechat/main/deploy/install.sh | bash
```

چند سؤال می‌پرسد (دامنه، توکن ربات، …)، همه‌ی رمزها را خودش می‌سازد، گواهی Cloudflare را می‌گیرد و همه‌چیز را بالا می‌آورد. برای به‌روزرسانی همین دستور را دوباره اجرا کنید. جزئیات: [راه‌اندازی روی سرور](docs/DEPLOYMENT.md).

## اجرای محلی روی ویندوز (بدون Docker)

پیش‌نیاز: Node.js 22.12 یا بالاتر.

```bash
npm run install:all
```

ترمینال ۱ — سرور (Postgres داخلی، Redis در حافظه، ۳۰ پروفایل نمونه، درگاه پرداخت آزمایشی):

```bash
npm run dev:server
```

ترمینال ۲ — مینی‌اپ:

```bash
npm run dev:miniapp
```

http://localhost:5173 را باز کنید. بیرون از تلگرام یک کاربر آزمایشی ساخته می‌شود؛ با `?u=2`، `?u=3` و… کاربران دیگری بسازید و در دو تب با هم چت کنید.

ترمینال ۳ (اختیاری) — پنل مدیریت روی http://localhost:3000 با `admin` / `admin12345`:

```bash
npm run dev:admin
```

### تست داخل خود تلگرام در حین توسعه

1. یک ربات تستی بسازید و `apps/server/.env.local` با `BOT_TOKEN=...` و `BOT_USERNAME=...` بنویسید (ربات با long polling اجرا می‌شود).
2. مینی‌اپ و API را با یک تونل HTTPS در دسترس بگذارید، مثلاً:

```bash
cloudflared tunnel --url http://localhost:5173
```

3. آدرس تونل را در BotFather (`/newapp` یا `/myapps`) به‌عنوان آدرس وب‌اپ بدهید، `VITE_API_URL` در `apps/miniapp/.env.local` را به تونل دوم API (پورت 4000) بدهید و آدرس تونل مینی‌اپ را به `CORS_ORIGINS` در `apps/server/.env.local` اضافه کنید.

## تست‌ها

```bash
npm test
```

تست یکپارچه با PostgreSQL واقعی: ورود با initData امضاشده (و رد امضای جعلی/منقضی)، چرخش refresh token، ثبت‌نام دو مرحله‌ای، دعوت و جایزه، مچ و چت و اعلان تلگرامی با محدودیت تکرار، سوپرلایک هدیه، پرداخت و فعال‌سازی یک‌باره‌ی عضویت.

## نکات طراحی

- **ورود:** کاربر با باز کردن ربات/مینی‌اپ خودکار ثبت‌نام می‌شود؛ ثبت‌نام فقط جنسیت، سن و یک عکس است (عکس تلگرام خودکار گذاشته می‌شود و نام از تلگرام پر می‌شود).
- **نوار بالای تلگرام:** اپ هیچ دکمه‌ی برگشتی رسم نمی‌کند؛ دکمه‌ی Back تلگرام با ناوبری اپ (صفحه‌ها، شیت‌ها، دیالوگ‌ها) همگام است و رنگ نوار با پس‌زمینه‌ی اپ یکی می‌شود. سوایپ عمودی تلگرام خاموش است تا سوایپ کارت‌ها اپ را نبندد.
- **رشد:** لینک دعوت اختصاصی با هدیه‌ی دوطرفه، کارت دعوت inline در هر چت، اشتراک در استوری، دیده‌شدن بیشتر تازه‌واردها، و اعلان‌های ربات برای برگرداندن کاربران.
